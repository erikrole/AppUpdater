- The live suite fetched and verified the real Offload DMG plus StatBar, PowerBar, Tweaks, and UpdateBar ZIPs in temporary locations. It never swapped, installed, or launched those payloads. Existing read-only GitHub authentication was supplied only to the test process after the shared unauthenticated API quota was exhausted.
- ZIPs retain the same signature, Apple certificate anchor, Team ID, bundle ID, version, and Gatekeeper requirements as DMGs. Extraction rejects escaping links, hard links, special file types, oversized archives, and ambiguous app payloads.

## Lifecycle review

Each app owns a single updater and offers a manual check. Automatic checks are Release-only, outside tests and CLI helper modes. TVBar checks automatically only when maintenance Settings is explicitly opened, keeping login and widget-command launches quiet.

Quit is blocked during preparation; after verified helper handoff, existing host safeguards still run. SnipBar keeps its save/retry guard; UpdateBar waits for active installers; Cutdown waits for calendar operations; TVBar waits for queued commands; Tweaks retains bounded Wi-Fi restoration. No forced-exit fallback is configured.

An independent source review found and confirmed fixes for Tweaks busy state across draining Downloads sessions and closed image-export windows, plus system-shutdown restoration. A deterministic Downloads concurrency regression verifies busy state survives watcher stop/restart until the old transaction drains.

## Delivery boundary

Host end-to-end update/relaunch UI flows were not exercised individually; shared payload verification, installer/quit regressions, host unit suites, Release builds, and lifecycle source review supply the current evidence.
